Vice Shores — a complete open-world crime game in the spirit of GTA 6, built for the make.fun gta6-01 bounty: a procedural 3D city to explore on foot and by car, with traffic and pedestrians, carjacking, a 5-star wanted system with police pursuits, 6 story missions, combat, a HUD with a minimap, a start screen and saves — running offline in a desktop browser from static files.

## Run it

```sh
node serve.ts
# then open http://127.0.0.1:8080/ in a desktop browser
```
